# Aquant PRD v1.0 验收清单

## 市场数据

- [x] 市场数据只展示客观原始字段，不展示 Market Score。
- [ ] 热门板块只展示平台原始排名/热度字段，不展示 Sector Score。
- [x] 热门个股只展示平台原始排名和原始分数，不做综合评分。
- [ ] 涨停股展示平台原始涨停原因。
- [x] 市场页“+ 自选”走用户提交接口，不自动入池。

## 自选股

- [x] 自选股全部由用户手动入选。
- [x] 重复添加有效自选不创建重复记录。
- [x] 状态变化写入状态日志。
- [ ] 删除为逻辑剔除，不物理删除历史。
- [x] 黑名单股票重新加入有风险提示或二次确认。
- [x] 加入自选必须填写交易系统、入选理由、关键观察价、失效条件。
- [x] 自选观察、信号、交易主流程统一使用英文状态 code。

## K 线与指标

- [ ] K 线仅用于后台计算、信号触发和复盘统计。
- [x] H5 前台不展示个股 K 线图。
- [x] 个股 K 线查看统一跳转雪球。

## 信号

- [x] 只有手动自选且开启监控的股票能生成买入观察信号。
- [x] 同一股票、同一买点、同一交易日信号去重。
- [ ] 卖出/风险信号优先于买入观察信号。
- [ ] 信号文案体现“仅作为交易辅助，请结合个人交易规则确认”。

## 交易记录

- [x] 确认买入写入 `watch_trade`。
- [x] 确认买入写入 `watch_trade_execution` 买入流水。
- [x] 确认卖出写入 `watch_trade_execution` 卖出流水。
- [x] MVP 仅支持全部卖出，前端无部分卖出入口。
- [x] 全部卖出触发单笔交易复盘。
- [x] 不存在自动下单、券商接口、一键下单。

## 复盘

- [ ] 可生成周复盘表单。
- [ ] 可生成月复盘表单。
- [ ] 可生成单笔交易复盘卡片。
- [ ] 无交易周期仍生成复盘表单。
- [ ] 用户可保存、完成、归档复盘。

## 我的模块

- [ ] 可查看用户资料。
- [ ] 可查看和保存偏好。
- [ ] 可查看消息设置。
- [ ] 可查看待办和系统摘要。
- [ ] 可查看后台入口状态。

## 后台管理

- [ ] 数据源可管理。
- [ ] 采集任务可管理和手动执行。
- [ ] 字段映射、字典、策略、模板可管理。
- [ ] 任务日志和操作日志可查询。
- [ ] 敏感配置脱敏返回。

## H5

- [x] 底部导航为市场、自选、复盘、我的。
- [ ] loading/empty/error/success 状态完整。
- [ ] 高风险操作有确认。
- [x] 股票名称统一跳转雪球。
- [x] 自选交易 Tab 不基于 `watch_pool` 伪造交易列表。
- [x] 无违规诱导文案。

## 合规

- [x] 单用户个人使用系统。
- [x] 无自动交易。
- [x] 无自动入池。
- [x] 无主观市场/板块/自选评分展示在主导航流程中。
- [x] 无前台 K 线图。
- [x] 买卖均由用户人工确认。
- [ ] 数据源合规边界清晰。
