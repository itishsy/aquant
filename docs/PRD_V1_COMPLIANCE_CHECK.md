# Aquant PRD v1.0 合规检查

状态：自选池管理模块最终清理后通过核心合规检查。

## 必须保持

- [x] 单用户个人使用系统。
- [x] 不实现多账号、多租户、团队权限或复杂 RBAC。
- [x] 不实现自动下单、自动报单、自动撤单。
- [x] 不实现券商接口、一键下单、跟单、自动交易。
- [x] 所有买入、卖出操作均由用户人工确认。
- [x] 市场模块不展示主观市场评分。
- [x] 热门个股不做综合加分、扣分或主观排序。
- [x] 自选股全部由用户手动入选。
- [x] H5 前台不展示个股 K 线图。
- [x] 个股 K 线查看统一跳转雪球。
- [x] 信号、交易、复盘、提醒文案体现“仅作为交易辅助，请结合个人交易规则确认”。

## 本轮发现与处理

- 自动入池已降级为 no-op。
- Market Score / Sector Score / Watch Score 旧字段未删除，但不在最新 H5 主导航流程中展示或作为入选依据。
- 自选池不再依赖 `operation_strategies` / `buy_point_types` 作为主流程必填或核心判断字段。
- 自选页交易 Tab 只读取 `watch_trade` / `watch_trade_execution`，不再从 `watch_pool` 伪造交易列表。
- MVP 卖出流程仅保留用户人工确认全部卖出，前端无部分卖出入口。
- 中文旧状态兼容判断已从自选、信号、交易、复盘主流程移除，统一使用英文 code。
- 后台管理页已停用旧自选池编辑表单，避免重新引入旧字段主流程。
