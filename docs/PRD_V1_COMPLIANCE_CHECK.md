# Aquant PRD v1.0 合规检查

状态：迁移中。

## 必须保持

- [x] 单用户个人使用系统。
- [x] 不实现多账号、多租户、团队权限或复杂 RBAC。
- [x] 不实现自动下单、自动报单、自动撤单。
- [x] 不实现券商接口、一键下单、跟单、自动交易。
- [x] 所有买入、卖出操作均由用户人工确认。
- [x] 市场模块不展示主观市场评分。
- [x] 热门个股不做综合加分、扣分或主观排序。
- [x] 自选股全部由用户手动入选。
- [x] H5 前台不展示个股 K 线图。
- [x] 个股 K 线查看统一跳转雪球。
- [x] 信号、交易、复盘、提醒文案体现“仅作为交易辅助，请结合个人交易规则确认”。

## 本轮发现与处理

- 自动入池已降级为 no-op。
- Market Score / Sector Score / Watch Score 旧字段未删除，但不在最新 H5 主导航流程中展示或作为入选依据。
- H5 个股 K 线图已移除。
- v1.1 每日计划、严格模式、能力评分保留旧代码但从底部导航隐藏，后续按实验能力归档。

## 禁止文案扫描项

- 立即买入
- 必涨
- 稳赚
- 强烈推荐
- 一键下单
- 自动交易
- 跟单
