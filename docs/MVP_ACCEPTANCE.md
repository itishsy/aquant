# MVP Acceptance Checklist

## 数据采集验收

- [x] Mock provider 可采集市场、板块、热门股、涨停股、日 K、15 分钟 K
- [x] 数据标准化通过
- [x] 数据质量校验失败时不进入信号流程

## 自选池验收

- [x] 可手动增删自选
- [x] 可更新标签与黑名单
- [x] 可基于热门股/主线板块/涨停质量自动入池

## 信号验收

- [x] 信号引擎可注册/扫描策略
- [x] 15 分钟 MACD 底背离买入观察信号可识别
- [x] 风险信号优先于买入观察信号
- [x] `signal_record` 保存 `raw_snapshot`

## H5 验收

- [x] 市场页可展示市场温度、板块、热门股、涨停分析、风险提示
- [x] 自选池/个股详情/信号/交易/复盘页面可访问
- [x] 无自动交易或诱导交易入口

## 复盘验收

- [x] 可生成周度复盘
- [x] 可统计胜率、盈亏比、总盈亏、最大回撤

## 合规边界检查

- [x] 全部信号包含“仅作为交易辅助”
- [x] 不出现“立即买入 / 必涨 / 稳赚 / 强烈推荐买入 / 自动交易”
- [x] 无真实券商接口与自动下单能力
