# Aquant 自选生命周期管理 PRD 1.0

> 文档类型：产品需求文档（PRD）  
> 模块名称：自选生命周期管理  
> 所属系统：Aquant 量化分析与交易辅助系统  
> 版本：v1.0  
> 适用范围：H5 前台、自选池、交易系统绑定、买入提醒、交易确认、卖出提醒、复盘入口  
> 核心原则：系统负责规则识别与提醒，用户负责最终交易确认；系统不自动下单。

---

## 1. 背景与目标

Aquant 的自选池不是普通股票收藏夹，而是一个短线交易候选漏斗。股票从市场页热榜、涨停榜进入自选后，必须绑定明确的交易系统，并在该交易系统的规则约束下完成从观察、信号、买入、交易中、卖出到复盘的完整生命周期。

本 PRD 1.0 重点解决以下问题：

1. 股票如何从市场页加入自选。
2. 加入自选时如何确认交易系统。
3. 观察池中的股票如何根据所属交易系统自动生成买入信号。
4. 买入信号生成后，系统如何继续判断买点确认方法。
5. 买点满足后，如何提醒用户人工确认买入。
6. 用户确认买入时需要填写哪些字段，尤其是必须确认止损位。
7. 买入后如何进入交易页的交易中状态。
8. 交易中如何触发卖出信号并完成全部卖出。
9. 卖出后如何进入复盘流程。

---

## 2. 产品定位

自选生命周期管理模块用于管理股票从“市场候选”到“交易完成”的全过程。

该模块不直接承担复杂交易系统细节的定义。三套交易系统的具体规则将在下一阶段单独分析，包括：

1. 平台突破体系。
2. 上涨趋势体系。
3. 追涨接力体系。

本 PRD 只定义生命周期流程、页面交互、状态流转、表单字段、权限边界和验收标准。

## 3. 核心设计原则

### 3.1 加入自选必须确认交易系统

股票从市场页加入自选时，必须选择一套交易系统。

系统会默认选中推荐交易系统，用户可以直接修改为其他交易系统，但不需要填写修改原因。

可选交易系统包括：

```text
平台突破
上涨趋势
追涨接力
```

### 3.2 交易系统决定后续规则

交易系统一旦确认，以下内容均由该交易系统限定：

```text
观察策略
买入信号规则
买点确认方法
止损策略
止盈策略
卖出信号规则
```

用户在加入自选时不需要填写这些规则。

### 3.3 系统自动识别信号，用户人工确认交易

观察池个股根据所属交易系统自动扫描买入信号。

当买入信号生成后，系统继续判断是否满足买点确认方法。只有买点确认方法满足后，系统才提醒用户买入。

用户必须人工确认买入，系统不自动下单。

### 3.4 确认买入时必须确认止损位

用户点击确认买入时，必须填写或确认止损位。

未确认止损位，不允许完成买入确认。

### 3.5 只有人工确认买入后，才进入交易页的交易中

买入信号已生成、等待买点确认、买入待确认，都不等于实际交易。

只有用户人工确认买入后，股票才进入交易页的“交易中”。

### 3.6 放弃本次机会后不得重复生成同一信号

用户可以放弃本次机会，股票回到观察中。

但本次已放弃的信号不得再次生成新信号，避免重复打扰。

### 3.7 MVP 只支持全部卖出

MVP 阶段仅支持全部卖出，不支持部分卖出。

## 4. 底部导航与模块边界

H5 底部导航包括四个入口：

```text
市场 ｜ 自选 ｜ 交易 ｜ 复盘
```

### 4.1 市场

市场页负责发现机会。

主要内容：

1. 市场状态。
2. 热门板块。
3. 热榜。
4. 涨停榜。
5. 股票详情入口。
6. 加入自选入口。

市场页不负责买入确认和卖出处理。

### 4.2 自选

自选页负责观察和信号展示。

自选页内部包括：

```text
观察 ｜ 信号
```

其中：

1. 观察：展示已加入自选并处于观察中的股票。
2. 信号：展示已生成买入信号、等待买点确认、买入待确认的股票。

### 4.3 交易

交易页负责已经进入实际交易流程的事项。

交易页包括：

1. 买入待确认提醒入口。
2. 交易中。
3. 卖出提醒。

注意：股票只有在用户人工确认买入后，才进入交易页的“交易中”。

### 4.4 复盘

复盘页负责交易完成后的总结。

复盘页包括：

1. 日计划。
2. 单笔交易复盘。
3. 周复盘。
4. 月总结。

## 5. 生命周期状态定义

### 5.1 状态总览

| 状态 | 含义 | 所在页面 | 是否代表真实交易 |
|---|---|---|---|
| 市场候选 | 股票出现在热榜、涨停榜，尚未加入自选 | 市场 | 否 |
| 观察中 | 已加入自选，已确认交易系统 | 自选-观察 | 否 |
| 买入信号已生成 | 系统根据交易系统规则识别出买入信号 | 自选-信号 | 否 |
| 等待买点确认 | 买入信号已生成，但买点确认方法尚未满足 | 自选-信号 | 否 |
| 买入待确认 | 系统判断买点确认方法已满足，提醒用户买入 | 自选-信号 / 交易提醒入口 | 否 |
| 交易中 | 用户人工确认买入，已记录实际交易 | 交易 | 是 |
| 卖出信号待处理 | 系统触发卖出信号，等待用户确认卖出 | 交易 | 是 |
| 卖出延后处理 | 用户选择暂不处理卖出提醒 | 交易 | 是 |
| 已卖出 | 用户确认全部卖出 | 交易 / 复盘 | 已结束 |
| 待复盘 | 已卖出但尚未完成复盘 | 复盘 | 已结束 |
| 已归档 | 生命周期结束，进入历史归档 | 复盘 / 归档 | 已结束 |
| 已失效 | 观察逻辑失效，退出观察 | 自选 | 否 |
| 黑名单 | 禁止再次自动入池 | 自选 / 后台 | 否 |

### 5.2 主状态流转

```text
市场候选
  ↓ 加入自选并确认交易系统
观察中
  ↓ 系统识别买入信号
买入信号已生成
  ↓ 系统判断买点确认方法
等待买点确认
  ↓ 买点确认方法满足
买入待确认
  ↓ 用户人工确认买入并确认止损位
交易中
  ↓ 系统触发卖出信号
卖出信号待处理
  ↓ 用户确认全部卖出
已卖出
  ↓ 系统生成复盘任务
待复盘
  ↓ 用户提交复盘
已归档 / 重新观察 / 黑名单
```

### 5.3 异常状态流转

```text
观察中 → 已失效
观察中 → 移除自选
买入信号已生成 → 放弃本次机会 → 观察中
等待买点确认 → 放弃本次机会 → 观察中
买入待确认 → 放弃本次机会 → 观察中
卖出信号待处理 → 卖出延后处理
卖出延后处理 → 卖出信号待处理
待复盘 → 已归档
待复盘 → 观察中
待复盘 → 黑名单
```

## 6. 市场页交互流程

### 6.1 市场页股票卡片

市场页热榜、涨停榜中的股票卡片展示：

| 字段 | 说明 |
|---|---|
| 股票名称 | 中文名称 |
| 股票代码 | 标准股票代码 |
| 当前涨跌幅 | 当前行情表现 |
| 入选来源 | 热榜 / 涨停榜 |
| 所属板块 | 个股所属题材或行业 |
| 系统推荐交易系统 | 平台突破 / 上涨趋势 / 追涨接力 |
| 推荐理由 | 系统识别原因 |
| 风险标签 | 高位、封板弱、缩量、板块转弱等 |

### 6.2 市场页股票卡片按钮

```text
加入自选
查看详情
忽略
```

### 6.3 点击“加入自选”

点击后弹出底部抽屉：

```text
确认交易系统并加入自选
```

### 6.4 表单：确认交易系统并加入自选

| 字段 | 类型 | 是否必填 | 说明 |
|---|---|---|---|
| 股票名称 | 只读 | 是 | 自动带入 |
| 股票代码 | 只读 | 是 | 自动带入 |
| 入选来源 | 只读 | 是 | 热榜 / 涨停榜 |
| 所属板块 | 只读 | 是 | 自动带入 |
| 系统推荐交易系统 | 只读 | 是 | 系统自动识别 |
| 用户确认交易系统 | 单选 | 是 | 默认选中系统推荐交易系统，用户可直接修改 |
| 入选理由 | 多选 + 文本 | 是 | 系统生成，可编辑 |
| 关键观察价 | 数字 | 是 | 箱体上沿 / MA20 / MA5 等 |
| 失效条件 | 文本 | 是 | 系统建议，可编辑 |
| 风险标签 | 多选 | 否 | 高位、封板弱、缩量、板块转弱等 |
| 备注 | 文本 | 否 | 用户补充 |

### 6.5 交易系统选项

```text
平台突破
上涨趋势
追涨接力
```

### 6.6 不在加入自选时填写的内容

以下内容由交易系统自动限定，不需要用户在加入自选时填写：

```text
观察策略
买入信号规则
买点确认方法
止损策略
止盈策略
卖出信号规则
```

### 6.7 表单按钮

```text
确认加入自选
取消
```

### 6.8 提交后系统动作

用户点击“确认加入自选”后，系统执行：

1. 创建自选股记录。
2. 写入股票基础信息。
3. 写入入选来源。
4. 写入用户确认交易系统。
5. 写入入选理由。
6. 写入关键观察价。
7. 写入失效条件。
8. 写入风险标签。
9. 启用该交易系统对应的观察扫描逻辑。

状态流转：

```text
市场候选 → 观察中
```

## 9. 系统自动生成买入信号

### 9.1 生成机制

观察池个股根据所属交易系统自动扫描买入信号。

每套交易系统必须配置：

```text
观察策略
买入信号规则
买点确认方法
止损策略
止盈策略
卖出信号规则
```

这些规则不在本 PRD 中展开，下一阶段单独分析三套交易系统细节。

### 9.2 买入信号生成后

当系统识别到买入信号：

```text
观察中 → 买入信号已生成
```

如果买点确认方法尚未满足：

```text
买入信号已生成 → 等待买点确认
```

该股票展示在：

```text
自选 ｜ 信号
```

不进入交易页的“交易中”。

## 11. 放弃本次机会

### 11.1 入口

以下状态均允许放弃本次机会：

```text
买入信号已生成
等待买点确认
买入待确认
```

### 11.2 表单字段

| 字段 | 类型 | 是否必填 | 说明 |
|---|---|---|---|
| 放弃原因 | 单选 + 文本 | 是 | 用户选择原因 |
| 是否继续观察 | 开关 | 是 | 默认继续观察 |
| 是否保留信号记录 | 开关 | 是 | 默认保留 |

放弃原因选项：

```text
买点不清晰
风险收益比不合适
市场转弱
板块转弱
价格偏离买点
个人不想交易
```

### 11.3 状态流转

如果继续观察：

```text
买入信号已生成 / 等待买点确认 / 买入待确认 → 观察中
```

如果不继续观察：

```text
买入信号已生成 / 等待买点确认 / 买入待确认 → 已失效
```

### 11.4 防重复规则

回到观察中后，本次已放弃的信号不得重复生成。

系统需记录：

| 字段 | 说明 |
|---|---|
| abandoned_signal_id | 被放弃的信号 ID |
| abandoned_reason | 放弃原因 |
| abandoned_time | 放弃时间 |
| prevent_duplicate_signal | 是否禁止重复生成同一信号 |

## 20. 验收标准

### 20.1 加入自选验收

| 验收项 | 标准 |
|---|---|
| 加入自选必须选择交易系统 | 未选择交易系统无法提交 |
| 默认选中系统推荐交易系统 | 打开表单时自动选中推荐项 |
| 用户可修改交易系统 | 可切换为其他两套体系 |
| 不要求填写修改原因 | 修改交易系统后无需填写原因 |
| 加入成功后进入观察中 | 状态正确更新 |

### 20.2 观察与信号验收

| 验收项 | 标准 |
|---|---|
| 观察股按交易系统扫描 | 不同交易系统走不同扫描规则 |
| 买入信号自动生成 | 满足规则后生成信号记录 |
| 买点未满足不进入交易中 | 仅在自选-信号展示 |
| 买点满足后进入买入待确认 | 生成用户买入提醒 |
| 放弃信号不重复生成 | 相同信号不再重复提醒 |

### 20.3 买入确认验收

| 验收项 | 标准 |
|---|---|
| 只有买入待确认才能确认买入 | 其他状态无法确认买入 |
| 确认买入必须填写止损位 | 未填写止损位无法提交 |
| 目标价非必填 | 可为空 |
| 确认买入后进入交易中 | 状态正确流转 |
| 生成交易记录 | trade_record 正确写入 |

### 20.4 交易中与卖出验收

| 验收项 | 标准 |
|---|---|
| 交易中展示买入信息 | 买入价、仓位、止损位、盈亏完整展示 |
| 触发卖出信号后提醒 | 状态进入卖出信号待处理 |
| MVP 只支持全部卖出 | 不出现部分卖出选项 |
| 确认卖出后进入待复盘 | 状态正确流转 |
| 盈亏自动计算 | 盈亏金额、比例正确 |

### 20.5 复盘入口验收

| 验收项 | 标准 |
|---|---|
| 卖出后生成复盘任务 | 复盘页出现待复盘卡片 |
| 可开始复盘 | 进入单笔复盘流程 |
| 可归档 / 重新观察 / 加黑名单 | 状态正确流转 |

## 23. 总结

自选生命周期管理 PRD 1.0 的核心是建立一个清晰、克制、可执行的股票生命周期：

```text
市场发现
  ↓
确认交易系统并加入自选
  ↓
观察中
  ↓
系统生成买入信号
  ↓
系统判断买点确认方法
  ↓
提醒用户确认买入
  ↓
用户确认止损位并买入
  ↓
交易中
  ↓
系统触发卖出信号
  ↓
用户确认全部卖出
  ↓
复盘归档
```

一句话总结：

> 交易系统决定规则，系统负责识别信号和买点，用户负责最终买入卖出确认，自选池负责完整记录生命周期。
