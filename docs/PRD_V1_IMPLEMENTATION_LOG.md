# Aquant PRD v1.0 实施日志

基准文档：`Aquant PRD v1.0.md`（单用户开发就绪版）

## Phase 0：执行清单

状态：进行中

本次不是清空重写，而是在旧 MVP/v1.1 混合代码基础上，按最新 PRD 做迁移、停用冲突能力、补齐缺失能力。

### 必须先处理的冲突项

- 停用自动入池与自动更新自选池任务。
- 停用 Market Score / Sector Score / Watch Score 在 H5 主流程中的展示和使用。
- 移除 H5 个股 K 线图，保留雪球跳转。
- 将 v1.1 每日计划、严格模式、能力评分等能力降级为实验/隐藏入口。
- 确认无自动下单、券商接口、一键下单、跟单、自动交易入口。

### 数据库迁移项

- 新增 PRD 标准表：`mkt_*`、`watch_*`、`review_*`、`my_*`、`config_*`。
- 不删除旧表，不破坏旧字段。
- 为 PRD 指定唯一约束和索引建索引。
- 更新数据库最终文档。

### 后端服务项

- 新增统一响应、单用户登录边界、公共接口。
- 新增 `/api/h5/**` 适配层。
- 新增 PRD 市场数据服务，只处理原始字段。
- 改造自选池为手动入选。
- 改造信号、交易、复盘服务为 `watch_*` / `review_*` 模型。
- 新增我的模块与通知服务。
- 新增后台管理基础接口。

### H5 前台项

- 底部导航收敛为：市场、自选、复盘、我的。
- 市场页展示原始行情、人气榜、涨停榜。
- 市场页只通过“+ 自选”触发用户手动入选。
- 自选页包含观察、信号、交易。
- 复盘页包含周复盘、月复盘、单笔复盘入口。
- 我的页包含资料、待办、偏好、系统状态、后台入口。

### 后台管理项

- 后台基础页面与 API：工作台、数据源、任务、字段映射、字典、策略、模板、日志、账号安全。
- 后台写操作写入 `config_operation_log`。

### 定时任务项

- 默认任务配置来自 `config_task`。
- 任务执行写 `config_task_log`。
- 运行中任务禁止重复触发。

### 测试与文档项

- 更新测试基准，移除旧评分/自动入池主线断言。
- 增加 PRD 主流程测试。
- 更新 API、数据库、验收、合规、README。
