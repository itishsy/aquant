# Aquant v1.1 合规检查

## 边界声明

Aquant v1.1 仍然是“行情监测 + 辅助分析 + 信号提醒 + 人工确认 + 交易记录 + 复盘训练”系统，不实现自动化委托行为、不连接券商交易接口、不承诺收益。

## 禁止项检查

- [x] 未实现自动下单。
- [x] 未实现自动报单。
- [x] 未实现自动撤单。
- [x] 未接入券商交易接口。
- [x] 未出现诱导性买卖、收益确定性、自动化委托或快捷委托类文案。
- [x] 严格模式仅用于系统内流程控制，不影响真实账户。

## 风险控制检查

- [x] 热度数据只作为候选参考，不单独触发买入观察信号。
- [x] 数据异常或质量校验失败时不生成有效交易信号。
- [x] 黑名单不会被自动入池覆盖。
- [x] 计划外交易被识别、记录并进入复盘统计。
- [x] 后台任务失败写入 `system_task_log`。
- [x] 敏感配置不返回前端。

## 扫描结果

2026-04-30 已执行合规关键词扫描：`rg` 范围 `app frontend/src docs tests` 无禁用文案命中。

## 标准文案

所有信号、计划、提醒和复盘文案应包含或体现：仅作为交易辅助，请结合个人交易计划确认。
