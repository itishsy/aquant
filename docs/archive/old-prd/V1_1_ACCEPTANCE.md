# Aquant v1.1 验收清单

## 自选股流程

- [x] 生命周期可完整流转并保留历史。
- [x] 自动入池有评分、原因、分层和风险说明。
- [x] 自动剔除进入归档，不删除历史。
- [x] 黑名单不得自动入池。

## 每日计划

- [x] 每个交易日可生成今日计划。
- [x] 根据市场状态判断交易权限。
- [x] 每个计划项包含触发条件、止损、目标、仓位、失效条件。
- [x] 计划可触发、取消、失效和完成统计。

## 买入前检查

- [x] 确认交易前生成检查清单。
- [x] 未设置止损不得通过。
- [x] 仓位超限有提示和阻断。
- [x] 严格模式下计划外交易不可确认。
- [x] 普通模式下计划外交易可标记并提醒。

## 卖出计划

- [x] 可生成止损、止盈、减仓、清仓计划。
- [x] 可确认部分卖出或全部卖出。
- [x] 全部卖出后触发单笔复盘待办。

## 复盘系统

- [x] 每笔完成交易可生成复盘卡片。
- [x] 用户可保存主观复盘和错误标签。
- [x] 周复盘包含计划执行率、计划外交易、错误统计。
- [x] 月度总结包含能力评分和改进目标。
- [x] 重复错误可生成提醒。

## H5 页面

- [ ] `/watch-pool` 支持状态、分层、评分和生命周期展示。后端已完成，H5 完整筛选弹层后续增强。
- [x] `/daily-plan` 可展示和维护今日计划。
- [x] 确认交易入口展示检查清单。
- [x] `/trades/:tradeId/review` 可编辑单笔复盘。
- [x] `/reviews` 增强周复盘，新增月度总结入口。

## 合规边界

- [x] 无自动下单、自动报单、自动撤单、券商交易接口。
- [x] 无收益承诺和诱导性买卖文案。
- [x] 交易动作均为用户人工确认。
- [x] 严格模式仅限制系统内确认流程。
- [x] 所有信号、计划、提醒体现“仅作为交易辅助，请结合个人交易计划确认。”
